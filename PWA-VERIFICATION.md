# Проверка установки на телефон

19.11.2026. Настоящий Google Chrome, отдельный временный профиль, Playwright.
Данные выдуманные, личный профиль браузера не использовался.

## Локальная проверка

- Chrome DevTools Protocol Page.getAppManifest: ошибок нет.
- Page.getInstallabilityErrors: пустой список, требования установки выполнены.
- PNG в манифесте декодируются с размерами 192x192 и 512x512.
- Service worker активировался и управляет страницей.
- После отключения сети страница перезагружается; привычка и отметка остаются.
- Без сети добавлена ещё одна привычка; повторная перезагрузка сохраняет её.
- При переходе VERSION 1 → 2 старые вкладки закрыты, новый кеш активен,
  старый кеш приложения удалён, localStorage не изменён, чужой кеш сохранён.
- Проверка кода обнаружила риск старых файлов из HTTP-кеша. Исправлено:
  предварительная загрузка использует cache: reload. Повторный тест с max-age=600
  подтвердил, что кеш версии 2 содержит новый app.js с маркером deployment 2.
- При VERSION 3 и ответе 503 на иконку обновление не установилось:
  предыдущая версия продолжила открываться без сети, привычки остались.
- На ширине 390 px горизонтальной прокрутки нет. Снимок pwa-local-mobile.png просмотрен.
- Ошибок JavaScript в основном сценарии нет. node --check sw.js и pwa.js прошли.

## Ограничения

Автоматическая проверка Chrome не подтверждает установку на настоящем телефоне.
Проверку иконки, запуска без адресной строки и режима полёта выполняет владелец.
Первое открытие должно завершиться с интернетом.
Для обновления закрыть все окна приложения и вкладки сайта и открыть снова с сетью.
