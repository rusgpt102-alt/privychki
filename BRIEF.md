# Привычки

Статус: бриф согласован владельцем 18.11.2026 ответом «да».

## Задача
Помочь мне отмечать выполнение привычек по дням и видеть прогресс за неделю.

## Кто пользуется
Только я. Приложение открывается по ссылке в браузере на компьютере и телефоне.

## Что уже есть
Есть отдельный приватный проект напоминаний и утренней сводки в Telegram.
Этот трекер создаётся отдельно. Существующие файлы, бот и настройки не меняются.
Первая версия приложения создана. Публикация на GitHub Pages согласована владельцем ответом «да».

## Экраны и кнопки
Один основной экран «Моя неделя»:
- Название приложения и даты выбранной недели.
- Поле названия привычки и кнопка «Добавить».
- Список привычек с отметками за семь дней. Нажатие ставит или снимает отметку.
- Кнопки «Предыдущая неделя», «Следующая неделя» и «Эта неделя».
- Прогресс каждой привычки: число выполненных дней из семи.
- При пустом списке: подсказка «Добавьте первую привычку».
- На телефоне названия и отметки читаемы, кнопки доступны для нажатия пальцем.

## Данные и хранение
Вводим названия привычек и отметки выполнения по календарным датам.
Для каждой привычки сохраняются внутренний идентификатор, название, дата создания и отмеченные даты.
Данные автоматически сохраняются в браузере на этом устройстве.
После закрытия и повторного открытия страницы в том же браузере отметки сохраняются.
Очистка данных сайта удалит записи. Приватный режим не подходит для постоянного хранения.
Телефон и компьютер хранят отдельные записи, автоматической синхронизации нет.
Личные отметки не включаются в код или файлы публичного репозитория.
Ключи, пароли и чужие персональные данные не используются.

## Первая версия: пять функций
1. Добавить привычку по непустому названию.
2. Поставить и снять отметку за сегодня или прошедший день, начиная с даты создания привычки.
3. Переключать недели и возвращаться к текущей.
4. Видеть прогресс каждой привычки за выбранную неделю.
5. Автоматически сохранять привычки и отметки в браузере.

## Предложения по мелким деталям
Эти решения предложены агентом и входят в согласование брифа:
- Неделя начинается в понедельник.
- Даты считаются по Екатеринбургу, UTC+5.
- Каждая привычка ежедневная, максимум одна отметка в день.
- Будущие дни и дни до создания привычки недоступны для отметок.
- Прогресс показывается как «3 из 7 дней»; у новой привычки он может быть меньше семи даже при выполнении каждый доступный день.
- Пустое название или название из пробелов не принимается, появляется понятная подсказка.

## Что не делаем сейчас
Калькулятор, журнал заказов, вход по паролю, базу данных, синхронизацию устройств,
уведомления, связь с Telegram.
Редактирование и удаление привычек, экспорт и импорт JSON уже реализованы по дополнительному запросу владельца.
Приложение предполагается разместить на GitHub Pages отдельным публичным проектом.
Публикация и настройка GitHub выполняются на шаге 4.

## Готово, когда: ручные проверки приложения
1. На компьютере и телефоне можно открыть страницу, прочитать названия и нажать кнопки.
2. Привычка с непустым названием появляется в списке; пустое название не добавляется.
3. Отметка за сегодня ставится и снимается; прогресс меняется между «0 из 7 дней» и «1 из 7 дней».
4. После перезагрузки и повторного открытия в том же браузере привычка и отметка остаются.
5. Переключение недель показывает соответствующие даты и отметки; кнопка «Эта неделя» возвращает текущую неделю. Будущие дни и дни до создания привычки отмечать нельзя.

## Установка на телефон, шаг 5

Манифест: manifest.webmanifest. Работа без интернета: sw.js.
Первый запуск нужен с интернетом, до завершения загрузки файлов приложения.
После этого приложение и отметки доступны без сети на этом устройстве.
Без адресной строки: standalone, на поддерживаемых устройствах fullscreen.

Обязательное правило каждой выкладки: повышать VERSION в sw.js (1, 2, 3 и далее),
включая выкладки с изменением документации. Не путать с version формата резервной копии.
Все необходимые файлы должны быть в FILES. Новая версия активируется после закрытия
всех вкладок и окон приложения и повторного открытия при наличии интернета.
Проверять переход со старой версии, сохранность привычек и запуск без сети.
Если кеш новой версии не загрузился целиком, предыдущая версия продолжает работать.
Кеши других приложений не очищаются. Данные localStorage при обновлении не меняются.

iPhone: открыть https://rusgpt102-alt.github.io/privychki/ в Safari,
«Поделиться» → «На экран „Домой“». Если есть переключатель «Открывать как веб-приложение», включить.
Android: открыть эту ссылку в Chrome, меню ⋮ → «Установить приложение»
или «Добавить на главный экран».
Проверка владельца: открыть с иконки, закрыть приложение, включить режим полёта и открыть снова.
Наличие иконки и поведение на настоящем телефоне подтверждает владелец.
