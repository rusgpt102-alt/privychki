# Проверка первой версии

Проверено 18.11.2026, дата чата. Браузерный день по Екатеринбургу во время запуска: 19.11.2026.

Playwright, локальный сервер http://127.0.0.1:8765, отдельный контекст с выдуманными записями:

- Пустое состояние и подсказка при пустом названии.
- Добавление, установка и снятие отметки, прогресс 0/7 и 1/7.
- Перезагрузка сохраняет название и отметку.
- Редактирование названия, запрет пустого названия, отмена редактирования.
- Предыдущая, следующая и текущая недели. Будущие даты и даты до создания недоступны.
- Скачивание JSON: прочитано содержимое файла, проверены привычка и отметка.
- Удаление выдуманной записи, отмена удаления.
- Импорт скачанного JSON, отмена импорта, сохранение после перезагрузки.
- Повреждённый JSON и несуществующая дата 30 февраля отклонены без изменения записей.
- Длинное название, ширина 390 px: горизонтальной прокрутки нет. Высота кнопок дней 44 px.
- Повторное открытие через ссылку названия и повторная перезагрузка сохраняют записи.
- Прошедший доступный день можно отмечать и снимать.
- Управляемые часы 31.12.2026 20:00 UTC: дата создания 01.01.2027 по Екатеринбургу, неделя 28 декабря / 3 января.
- Искусственный отказ localStorage.setItem: понятная ошибка, несохранённая привычка не показывается как сохранённая.
- Ошибок pageerror и console.error в основном сценарии нет.

Скриншоты просмотрены агентом: desktop.png (1440 px), mobile.png (390 px). Данные на снимках выдуманные, существуют только в тестовом браузере.

Локальный index.html отдельно открыт в пользовательском Google Chrome через file://. Через дерево доступности подтверждены заголовок, даты недели, пустое состояние и кнопки. Полный сценарий действий проверен через HTTP в Playwright, а не через file://.
