# План: погода в «Привычках»

Цель: согласована ответом «да погода». Открытая погода Екатеринбурга из Open-Meteo, без ключей и оплаты. Личные привычки остаются в localStorage.

Архитектура: Python стандартной библиотеки сохраняет проверенный JSON атомарно. GitHub Actions каждые три часа и вручную собирает данные, коммитит только data.json и явно публикует Pages. Браузер получает свежий JSON, service worker сохраняет последний удачный ответ для работы без сети.

Стек: Python 3.12, JavaScript, GitHub Actions, GitHub Pages.

Ограничения: никаких секретов, личных данных, платных сервисов, удаления или полной замены существующих файлов. Публикация и изменения разрешены исходным запросом и выбором источника. Исполнение самостоятельно, без дополнительных согласований мелочей.

Проверить: сбой сети и неправильный JSON не меняют старый файл; первая загрузка без данных даёт сообщение; старые данные заметно помечены; кеш не мешает обновлению; публикация запускается после автоматического коммита.
